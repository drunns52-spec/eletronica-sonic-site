Backup Eletrônica Sonic

Proteção e recuperação de dados do sistema

Sobre o aplicativo

O Backup Eletrônica Sonic é uma ferramenta de uso administrativo destinada à realização de cópias de segurança dos dados operacionais do sistema Eletrônica Sonic.

Integração com o Google Drive

O aplicativo solicita autorização para criar e gerenciar arquivos de backup no Google Drive do usuário autorizado.

A integração utiliza permissões limitadas aos arquivos utilizados pelo aplicativo.

Privacidade e segurança

Os arquivos de backup são destinados ao armazenamento privado e à recuperação autorizada dos dados.

Esta página não disponibiliza arquivos de backup nem permite acesso aos dados internos do sistema.
